PHP文件包含漏洞的产生原因是在通过PHP的函数引入文件时，由于传入的文件名没有经过合理的校验，从而操作了预想之外的文件，就可能导致意外的文件泄露甚至恶意的代码注入。   博文[https://www.secpulse.com/archives/3206.html](https://www.secpulse.com/archives/3206.html)

```
 <?php function foo() { echo "Hello World!\\n"; }?>
```
