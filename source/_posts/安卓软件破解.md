目标是得到软件VIP权限，两款软件均需要联网登陆，由于使用的环境权限较低，无法安装证书代理https，因此需要修改APK安装包。



## 环境准备：

1. 雷电模拟器
2. MT管理器
3. Jadx
4. JEB
5. LSPosed框架

学习资源：https://www.52pojie.cn/thread-1695141-1-1.html

## APP1：

使用 MT管理器对app重新签名安装运行发现没有任何异常， 判断该APP没有证书校验，因此修改比较简单。

通过在模拟器中抓包，可以找到到对应的域名，使用 Jadx 分析对应代码，可以看到是获取用户信息后，api接口返回对应的资源，本地再授予权限，并且接口未使用https。

![image-20250720085707729](/assets/image-20250720085707729.png)

因此使用MT管理器修改domain name，并使用 python监听返回固定的响应即可。

![image-20250720090711290](/assets/image-20250720090711290.png)

```python
from sanic import Sanic
from sanic.response import json

app = Sanic(__name__)

@app.route('/api/addUserInfo', methods=['POST'])  # 替换为你想要监听的URL
async def your_route2(request):
  data = {"id":1,"lock":"0","list":[{"type":"DT02","state":"1","date":"2050-02-03"},{"type":"DT01","state":"1","date":"2050-02-03"}]}
  print(data)
  return json(data) 

if __name__ == '__main__':
  app.run(host='0.0.0.0', port=80)`
```





## APP2：

同样先使用MT重新签名，签名后重新安装，发现打开即闪退。 可能存在签名校验，使用 MT自带各种方法去除签名验证均失败。

### 去除签名校验：

Jadx中搜索signatures 关键词，发现存在多处获取签名行为，并存在 kill自身进程的行为。

![image-20250720091822151](/assets/image-20250720091822151.png)

转换为 smali 代码后，可以看到有 以下两种 退出程序的方法

```java
Ljava/lang/System;->exit(I)V
Landroid/os/Process;->killProcess(I)V
```

![image-20250720092028135](/assets/image-20250720092028135.png)

在MT管理器中找到所有与该签名有关的 killprocess和exit，并将其直接注释。 重新打包后安装发现不会闪退了。

![image-20250720092239583](/assets/image-20250720092239583.png)



### 获取VIP：

继续分析，可通过抓取域名或搜索http相关关键词，可以找到服务端域名。

搜索VIP关键词，可以看到VIP类型是存放在vipType 成员中的，因此在MT管理器中直接修改`getVipType()`函数

并使用 1/2/3 代表不同的会员类型

**修改前：**

```java
    public Integer getVipType() {
        return this.vipType;
    }
```

对应smali代码：

```java
.method public getVipType()Ljava/lang/Integer;
    .registers 2

    .line 1
    iget-object v0, p0, Lcom/xxx/xxx/repertory/server/model/CLoginResponse;->vipType:Ljava/lang/Integer;

    return-object v0
.end method
```



**修改后：**

```java
    public Integer getVipType() {
        return new Integer(2);
    }
```

对应smali代码：

```java
.method public getVipType()Ljava/lang/Integer;
    .registers 3

    .line 1
    new-instance v0, Ljava/lang/Integer;

    const/4 v1, 0x2

    invoke-direct {v0, v1}, Ljava/lang/Integer;-><init>(I)V

    return-object v0
.end method
```



重新打包， 安装登陆， 登陆成功后即为VIP。
