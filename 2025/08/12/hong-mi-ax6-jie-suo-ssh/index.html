红米Ax6 解锁SSH并配置IPv6

接上篇，改为桥接模式后，红米AX6 默认ipv6防火墙也是开启的。

因此需要修改ip6tables， 但需要ssh root 权限。

1.解锁并固化ssh

工具：

  1. 按照https://blog.csdn.net/noob0208/article/details/128334126 先试用修复工具降级，再试用虚拟机搭建openwrt，获取到SSh权限

  2. 按照 https://www.right.com.cn/FORUM/thread-4046020-1-1.html 固化ssh，升级路由器固件，再使用telnet 恢复SSH权限

    sed -i 's/channel=.*/channel="debug"/g' /etc/init.d/dropbear
/etc/init.d/dropbear start

  3. 拨号上网， 之后连接到的设备均有IPv6地址

2.配置AX6 IPV6防火墙

尝试清空

检查现有规则
ip6tables -L -n -v
ip6tables -S


尝试清空
ip6tables -F
ip6tables -X
ip6tables -P INPUT ACCEPT
ip6tables -P OUTPUT ACCEPT
ip6tables -P FORWARD ACCEPT

测试，外网可以连接到内部设备的IPV6

但这种模式并不安全， 因为整个局域网所有设备均会IPv6暴露出去。

上网设置界面设置为 NAT6 ， 内网设备获取到的IP变成 内网IPv6，这样外网无法直接连通内网

小米路由器每次重启均会重置防火墙，使用以下命令，设置到开机启动将其转发

vi /etc/rc.local
#添加以下命令


ip6tables -t nat -A PREROUTING -p tcp --dport 8001 -j DNAT --to-destination [fd00:6868:6868::6b9]:5667
ip6tables -I forwarding_rule -p tcp --dport 5667 -j ACCEPT


#如果要删除可使用以下命令

#输出编号
ip6tables -t nat -L -n --line-numbers
ip6tables -t nat -D PREROUTING  1

可选：通过mac地址找ipv6

ip -6 neighbor show|grep 00:0c:29:00:9a:44|grep -v fe80

#脚本如下
# 提取 IPv6 地址（排除 fe80::）
TARGET_IPV6=$(ip -6 neighbor show | grep "00:0c:29:00:9a:44" | grep -v "fe80" | awk '{print $1}')

# 检查是否成功获取 IPv6 地址
if [ -z "$TARGET_IPV6" ]; then
    echo "错误：未找到该设备的 IPv6 地址！"
    exit 1
fi

# 生成并执行 ip6tables 规则
echo "添加规则：将 TCP 8001 转发到 [$TARGET_IPV6]:5667"
ip6tables -t nat -A PREROUTING -p tcp --dport 8001 -j DNAT --to-destination "[$TARGET_IPV6]:5667"
